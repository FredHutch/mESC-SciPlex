# Repository for Varnum-Finney & Heck et al. 2026

## Description

This is the repository containing the code used for analysis in the Varnum-Finney & Heck et al. 2026 paper.

### monocle:
- contains the compiled/finalized scripts for all [monocle3](https://cole-trapnell-lab.github.io/monocle3/) analyses performed in the project

### results:
- contains the final result tables
